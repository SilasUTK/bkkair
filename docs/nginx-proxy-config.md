# Hostinger Nginx Reverse Proxy Configuration

This file shows the exact Nginx configuration needed to route traffic correctly to both services.

## Location

Place this in: `/etc/nginx/sites-available/yourdomain.com` on your Hostinger server.

Or edit via Hostinger hPanel if you have direct Nginx editor access.

## Configuration

Replace `yourdomain.com` with your actual domain name.

```nginx
# HTTP → HTTPS redirect
server {
    listen 80;
    listen [::]:80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$server_name$request_uri;
}

# HTTPS server block
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;

    # ============================================
    # SSL Certificate Paths (auto-generated by Hostinger)
    # ============================================
    ssl_certificate /etc/ssl/certs/yourdomain.com.crt;
    ssl_certificate_key /etc/ssl/private/yourdomain.com.key;

    # SSL security settings
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # ============================================
    # Security Headers
    # ============================================
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "no-referrer-when-downgrade" always;
    add_header Permissions-Policy "geolocation=(), microphone=(), camera=()" always;

    # ============================================
    # API Routes → Express (port 5001)
    # ============================================
    location /api/ {
        proxy_pass http://127.0.0.1:5001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";
        proxy_http_version 1.1;

        # Timeouts for API requests
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # ============================================
    # Everything Else → Next.js Frontend (port 3000)
    # ============================================
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";
        proxy_http_version 1.1;

        # WebSocket support (if needed for live updates)
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # Timeouts for frontend requests
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # ============================================
    # Next.js static assets → frontend server
    # This must run before the generic asset cache rule so /_next/* is not
    # treated like a filesystem asset.
    # ============================================
    location ^~ /_next/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";
        proxy_http_version 1.1;
    }

    # ============================================
    # Static Asset Caching (1 year)
    # ============================================
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # ============================================
    # Deny Access to Sensitive Files
    # ============================================
    location ~ /\. {
        deny all;
    }

    location ~ \.env$ {
        deny all;
    }

    location ~ /\.git {
        deny all;
    }

    location ~ /node_modules {
        deny all;
    }

    # ============================================
    # Disable Access to Common Attack Vectors
    # ============================================
    location ~ \.(bak|conf|dist|fla|in[i]|lock|pem|sql|swp|~)$ {
        deny all;
    }
}
```

## How to Apply

### Via SSH:

```bash
# Create or edit the config file
sudo nano /etc/nginx/sites-available/yourdomain.com

# Paste the configuration above, update yourdomain.com to match your actual domain

# Test syntax
sudo nginx -t

# If test passes, reload Nginx
sudo systemctl reload nginx

# Verify it's running
sudo systemctl status nginx
```

### Via Hostinger hPanel:

1. Go to **Hosting** → **Nginx**
2. Look for your domain's config
3. Paste the configuration (update domain name)
4. Click **Save**

## Testing the Configuration

After applying the config, test each route:

```bash
# Frontend (should return HTML)
curl -I https://yourdomain.com/

# API health endpoint
curl https://yourdomain.com/api/health

# Check API is responding
curl -s https://yourdomain.com/api/health | jq .
```

## Troubleshooting

### 502 Bad Gateway

Frontend or API isn't running:

```bash
# Check processes
pm2 status

# Check if ports are listening
netstat -tuln | grep -E '3000|5001'

# View logs
pm2 logs
```

### SSL Certificate Error

Hostinger should auto-generate the certificate. If missing:

1. Go to **hPanel** → **SSL Certificates**
2. Generate a new one for your domain
3. Update certificate paths in Nginx config

### Nginx won't reload

Check syntax first:

```bash
sudo nginx -t
```

Fix any errors, then:

```bash
sudo systemctl restart nginx
```

## Performance Notes

- **Proxy buffering**: Enabled by default, good for large responses
- **Keep-alive**: Set via `Connection` header for efficiency
- **Gzip compression**: Consider adding `gzip on;` at top of http block
- **Rate limiting**: Can add `limit_req_zone` if needed
